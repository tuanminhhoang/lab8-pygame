🎮 Pygame Squares Mastery (HARD)

📚 Study Summary (Hard Difficulty)

This advanced study tool focuses on debugging, design tradeoffs, complexity analysis, and edge cases from the Pygame squares simulation. Mastering these concepts separates engineers who understand performance, correctness, and architecture from those who only know syntax.

Bugs & State Corruption

The code has subtle bugs: stale center values causing incorrect steering, zero-vector normalization crashes, and reference mutation issues in alive(). Understanding when and why these occur is critical for production code.

Complexity & Scalability

The O(N²) nearest-neighbor search works fine for 3 squares but fails catastrophically at 1000. Know when to use spatial hashing, quadtrees, or other optimization strategies. Understand the cost of coupling global constants to behavior.

Physics & Numerical Stability

Floating-point rounding, boost decay under frame drops, Euler integration drift, and system clock adjustments all introduce subtle bugs. Learn to design robust numeric code.

Design Tradeoffs

Why spawn with alive=False? Why hardcode RUNNING_TURN as a module constant? Why normalize before scaling? Each decision has implications for correctness, performance, and maintainability.

Reference & Lifecycle Invariants

Maintain the invariant: len(squares) == SQUARE_COUNT after update. Understand list slicing mutations, garbage collection, memory leaks from reference cycles, and when to use weak references.
